# 浮记图标
使用内置 image_gen 生成。原始图位于 floating-tasks.png；floating-tasks.ico 是保留透明通道的多尺寸封装（16/20/24/32/40/48/64/128/256）。
构建时同时作为 Windows EXE 图标和托盘/窗口的嵌入资源，无需用户另外复制图标文件。

生成提示词：
Use case: logo-brand. Create a single finished Windows app icon for 浮记, a tiny floating desktop task companion. No text. A bold mint green floating note with a simple dark checkmark, on a dark charcoal rounded square tile, matching a charcoal and mint desktop UI. Extremely simple, distinctive silhouette readable at 16x16 tray size. Flat crisp geometric graphic, centered, square image, tile fills most of canvas with small transparent margin. Genuinely transparent outside rounded square. No mockup, no lettering, no additional objects, no shadow outside tile. Deliver one icon.
